# Support

> **At a glance.** This is a research evaluation package maintained by one author.
> It is complete and parked; there is no service level. The fastest help is the
> package itself: `npm test` tells you whether everything still holds on your machine.

| Need | Where |
|---|---|
| Understand the system in ten minutes | [docs/OVERVIEW.md](docs/OVERVIEW.md) |
| Run, extend or check the package | [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) |
| The full technical reference | [RESEARCH.md](RESEARCH.md) |
| What is honestly still open | [docs/LIMITATIONS.md](docs/LIMITATIONS.md) |
| A result that does not reproduce, or a wrong number | [open a reproduction issue](https://github.com/andreibesleaga/sustainability-loop-eval/issues/new?template=reproduction.md) |
| A security problem | [SECURITY.md](SECURITY.md) — private reporting, never a public issue |
| Citing the work | [CITATION.cff](CITATION.cff) (GitHub renders a ready-made citation) |
| Reusing code, text or data | `LICENSE` and [NOTICE](NOTICE) — three different licences apply |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |

Questions about the article itself should wait for its publication; the package is
its replication material and stands on its own.
